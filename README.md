# Modern Developer Portfolio

A sleek, high-performance portfolio website featuring modern design patterns and smooth interactive elements.

##  Key Features

- **Modern Glass-morphism:** Translucent UI elements with backdrop filters and subtle shadows.
- **Dynamic Background:** Animated decorative blobs and smooth gradients for a premium feel.
- **Scroll Reveals:** Intersection Observer API used for elegant "reveal-on-scroll" animations.
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
- **Smooth Navigation:** Seamless scroll behavior and an interactive hamburger menu.

##  Built With

- **HTML5:** Semantic structure for accessibility.
- **CSS3:** Custom properties (CSS variables), Flexbox, and keyframe animations.
- **JavaScript:** Vanilla JS for DOM manipulation and intersection observer.
- **Google Fonts:** Poppins for clean typography.

##  Getting Started

1.  **Clone the repository:**
    ```powershell
    git clone https://github.com/AkshayaBalasubramani/Portfolio.git
    ```
2.  **Open locally:**
    Simply open `index.html` in your favorite browser, or use the **Live Server** extension in VS Code.
